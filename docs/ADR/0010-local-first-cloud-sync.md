# ADR-0010 — Account-scoped Local-first Cloud Sync

**Status:** Accepted

**Date:** 2026-10-25
**Authority:** 用户明确批准服务端与移动端同步实施计划。Accepted 不表示实现或验收完成。

## Decision

新增 `server/` Go 模块，使用 Kratos v3、sqlc/pgx 与 PostgreSQL 18。它负责邮箱密码账号、设备会话和版本化业务事实同步，不执行 Scheduler、不接管 Agent，也不替代设备 SQLite 的离线业务事务。服务端 SQL migration 是 PostgreSQL 机器事实源；现有 Drizzle Schema 仍是移动端 SQLite 机器事实源。

登录前明确说明上传目标、项目、任务、计划、执行/完成/成就、复盘、精力、放松和可移植偏好。登录后自动同步；未登录保持本地模式。本轮账号不验证邮箱、不提供密码重置，只验收内部本地联调，不授权公网部署。

同步以本地事务为原子批次，使用实体预期版本、稳定 batchId 与租户提交游标；响应丢失重放同一批次，不按设备时钟决定覆盖。版本、唯一事实或活跃会话冲突整体拒绝并保留两边证据。可变字段人工核对；完成、结束区间等证据不能强制覆盖，未采用分支作为只读冲突档案保存。

活跃专注/放松只有发起设备可操作，其他设备只读；离线并发执行进入显式冲突。计划版本与排程输入版本属于设备本地，远端计划变化在本地推进版本并使旧 Preview 失效。

Secret、完整 OperationRecord 收据/diff、系统日历缓存、OS identity/binding、IntegrationJob、ExternalMutationIntent 和派生特征缓存不上传。只同步必要的操作来源；完成/活动事实的 FK 通过新增来源表保持完整，不伪造本地幂等收据。

账号使用隔离的 SQLite 资料空间。首次游客资料认领保留来源与迁移证据，切账号不得混合数据。Token 仅进 SecureStore。前台事件合并驱动同步，停止/切账号后隔离迟到响应。

系统日历与通知由每台设备单独开启，新同步设备默认关闭。云端同步不授予修改第三方事件的权限，不传输 OS 绑定。

## Consequences

原 V1 不包含 Cloud Sync 的范围由本次用户决定扩展为内部账号与同步交付；不代表 Cloud Sync 已完成或正式发布。同步不提供端到端加密，生产传输必须 HTTPS；数据库加密、备份/导出、真实模型及商店门禁仍按 DEC-005/009 和发布规范独立验收。

服务端和 TypeScript 使用相同版本化实体字段清单及契约样例。迁移只追加，不能改写 `0000–0008`。跨租户、事务失败、冲突、恢复、无回声上传和跨设备归属必须有自动化验证。
